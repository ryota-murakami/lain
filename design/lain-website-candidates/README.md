# Lain — twelve website directions

A standalone static comparison site. It intentionally lives outside the pnpm app workspace.

- Deploy directory: `dist`
- Comparison page: `/`
- Candidate pages: `/W01/` through `/W12/`
- Build: `node scripts/build.mjs`
- Local preview: `python3 -m http.server 4317 --directory dist --bind 127.0.0.1`
- Browser QA: see `qa/README.md`

All bookmark examples are synthetic. No user account data or existing private screenshots are included. GitHub download links lead to release listings; platform packages must be checked before installing. Website copy deliberately labels export, sync, upload, updater controls and Linux as part of the preview scope until final product verification.

The owning agent manages private Sites registration and publication. No production website or domain is changed.
