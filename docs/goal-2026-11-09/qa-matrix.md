## Evidence handling and reproducibility

- Real account writes belong only to the root QA owner. The private ledger records every temporary collection/bookmark and cleanup state. Do not empty account trash globally.
- Public PR attachments must use synthetic data. Private real-account videos may include sidebar collection titles even when the selected bookmark is synthetic.
- Playwright recordings are inspected through extracted frames for transitions and multi-step flows. A still screenshot or passing locator does not establish smooth motion.
- macOS signing-only update QA and Apple notarization are separate claims. A synthetic auth fixture cannot verify production token restoration.
- Native export tests exercise actual temporary filesystem writes. A scripted save-dialog result verifies the write path, not the operating system dialog's visual behavior.
- A generated requirement-to-test mapping counts declarations. Only executed results linked to the final source can close acceptance items.
